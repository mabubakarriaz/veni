# Project Management Requirements

This project will follow the project management techniques outlined by the project management institute (PMI).

- The project is called "veni". A web application for waitlist in cafes and shops.
- This project is part of a program called "cert".
- The operations of this project will be the usage of the app. The buidling of the app will be the project.
- The project will be delivered in 4 phases. 1st phase is tanning of the features, 2nd phase is the development of the app, 3rd phase is testing and 4th phase is deployment.
- Project Life Cyle will be change driven and Iterative.
- The governance of the project will be the project documents to be filled given by the project management institute (PMI) as a sample.
- PMO type will be controlling. The project manager will be the one to control the project and make sure that the project is on track.
- The organization structure will be projectized.
- The project constraints will contain all 6 sides.
- The project will use all focus areas and domains of project management.
- The product will be the web app.
- The Risk register and issues logs will be maintained and updated throughout the project.
- Leadership style will be servant leadership. The project manager will be the one to serve the team and make sure that the team is motivated and productive.
- Add all the 6 PM priciples to the project management plan.
- Add phase reviews in the project.
